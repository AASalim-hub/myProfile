NSUK CHAT APP




The NSUK Chat App is a student-focused real-time communication platform I developed to provide students with dedicated spaces where they can communicate, share information, and interact with other students within the university community. The application is designed around different types of chat rooms, including general, faculty, department, and level-based rooms, allowing students to communicate in spaces that are relevant to them. It also includes features such as user registration and login, real-time messaging, room management, admin controls, and file sharing. I built the frontend and worked extensively on connecting the application to the backend using Node.js, Express.js, MongoDB, and Socket.io. I also used AI as a development assistant while working on the backend, particularly for understanding backend concepts, structuring parts of the server-side logic, debugging errors, and learning how the different components communicate with one another. Working on this project helped me understand how a real web application works beyond the frontend. I gained practical experience with APIs, databases, authentication, server-side programming, real-time communication, routing, and connecting a frontend application to a backend server. It also helped me improve my ability to read, debug, understand, and modify code rather than simply writing code that works.
